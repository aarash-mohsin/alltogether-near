# Claims and their evidence

Every claim AllTogether makes, with the code that implements it, the test that checks it, and the live evidence. "verify" means a line printed by `npm run verify` and shown on the [hosted verify page](https://aarash-mohsin.github.io/alltogether-live/#/verify), both computed from public NEAR testnet RPC when you run them.

Code references are to `contract/src/lib.rs` unless noted. Rust tests are in `contract/src/tests.rs`; application tests are under `tests/`.

## What we do not claim

- A funded plan proves the money was raised and paid out, not that the venue or supplier delivered.
- The DAO council is one test account, so a single vote passes a proposal.
- Testnet only, with a valueless test token. No external audit.
